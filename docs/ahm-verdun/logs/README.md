# Logs robot AHM Verdun — par année / mois / jour
Principe clic-clic : un dossier par jour, un fichier par robot / travail, un index par mois.
Structure : logs/AAAA/AAAA-MM/AAAA-MM-JJ/
Exemple : logs/2026/2026-10/2026-10-27/
Chaque fichier journal contient : date, robot (Muse / IA téléphone / IA site / IA courriel), tâche, libellé Gmail, résultat, erreur éventuelle, fichier GitHub / Drive lié.
Règle : si un robot fait une erreur, on note le robot, la date, le dossier et l'erreur — on ne supprime pas le log, on corrige dans un nouveau log.
Aucune donnée personnelle de mineur n'est publiée dans ces logs. Les coordonnées clients vont seulement dans clients/AAAA-AAAA/registre.md, et seulement quand le client les a fournies.
