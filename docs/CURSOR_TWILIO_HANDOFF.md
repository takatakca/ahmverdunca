## 1. Sync and certify the repository

From Cursor terminal:

```bash
git switch main
git pull --ff-only
git status
cd services/ahmv-voice-ai
npm ci
npm run check
npm run guardian
npm audit --omit=dev --audit-level=high
npm run release:report
```

Do not continue if any command fails.

## 2. Create the protected local Voice environment

Create `services/ahmv-voice-ai/.env` locally only. It is gitignored.

Use `.env.example` as the contract.

Required production/staging classes:

```env
NODE_ENV=production
PORT=3000

PUBLIC_BASE_URL=https://<public-voice-host>
PUBLIC_WSS_URL=wss://<public-voice-host>

TWILIO_ACCOUNT_SID=<secret>
TWILIO_AUTH_TOKEN=<secret>
TWILIO_PHONE_NUMBER=+15816666246
TWILIO_VALIDATE_SIGNATURES=true
TWILIO_SPEECH_MODEL=flux
TWILIO_TTS_VOICE=<approved ElevenLabs multilingual voice id>

OPENAI_API_KEY=<secret>
OPENAI_MODEL=gpt-5.6-terra

AHM_DATA_MODE=api
AHM_VOICE_BRIDGE_URL=https://ahmverdun.ca/api/ahmv/voice/
AHM_VOICE_BRIDGE_TOKEN=<same private secret used by the website>

SUPABASE_URL=<AHMV Supabase URL>
SUPABASE_SERVICE_ROLE_KEY=<server-only secret>
REQUIRE_PERSISTENT_STORE=true

VOICE_INSTANCE_MODE=single
SMS_ENABLED=true
```

Never paste these values into GitHub issues, PR comments, Cursor rules, committed files, or logs.

## 3. Cheapest safe first run

Before paying for another permanent server, run the Voice service locally and expose it through an HTTPS/WSS development tunnel that supports WebSockets.

The public tunnel origin must exactly match:
- `PUBLIC_BASE_URL`
- `PUBLIC_WSS_URL`

Then:

```bash
npm run preflight
npm start
```

From another terminal:

```bash
npm run smoke -- https://<public-voice-host>
npm run smoke:bridge -- https://ahmverdun.ca
```

Both must pass before Twilio is pointed at this test host.

A temporary tunnel is for sandbox calls only. Production remains `voice.ahmverdun.ca`.

## 4. Verify the Twilio webhook contract without changing the phone number

Run:

```bash
npm run smoke:twilio-signed -- https://<public-voice-host>/twilio/voice
```

Expected:
- valid Twilio signature → HTTP 200;
- response contains the press-1 `<Gather>`;
- ConversationRelay does NOT start before press 1;
- invalid signature → HTTP 403.

Stop if any expectation fails.

## 5. Capture rollback before any Twilio routing change

With the real Twilio credentials loaded locally:

```bash
npm run twilio:snapshot
```

This creates a protected local rollback snapshot under `.local/`.

Verify the snapshot identifies exactly:
`+1 581-666-6246`

Do not commit the snapshot.

## 6. Twilio sandbox / controlled-number configuration

Prefer a test/staging Twilio number first.

Configure the Voice webhook to:

`POST https://<public-voice-host>/twilio/voice`

Configure the call status callback, where supported by the chosen Twilio flow, to:

`POST https://<public-voice-host>/twilio/voice/status`

ConversationRelay itself connects to the WSS endpoint generated by the TwiML:
`wss://<public-voice-host>/twilio/conversation`

Do not configure Twilio to bypass `/twilio/voice` and connect directly to ConversationRelay. The press-1 gate must execute first.

1. FR — press 1 — ask next game.
2. EN — press 1 — ask practice.
3. ES — press 1 — ask arena/address.
4. Do not press 1.
5. Interrupt the assistant while speaking.
6. Change language during a call.
7. Schedule no-match.
8. Stale/unavailable schedule source.
9. Arena lookup.
10. SMS recap.
11. Say no text / opt out.
12. Duplicate callback → exactly one recap SMS.
13. Private/anonymous caller → no SMS.
14. OpenAI failure/timeout.
15. Bridge failure.
16. Reconnect path.
17. Max call duration.
18. Concurrency busy path.
19. Service restart/drain.

Do not call the public number "production-ready" until every critical case is green.

## 11. Public-number cutover

Only after all CI, Guardian, DB, host and real sandbox tests pass.

Immediately before the cutover:
1. run `npm run twilio:snapshot`;
2. preserve the existing Twilio voice URL/method/application/trunk values;
3. change the production number Voice webhook to:
   `POST https://voice.ahmverdun.ca/twilio/voice`;
4. make one controlled FR call;
5. make one controlled EN call;
6. make one controlled ES call;
7. verify exactly one recap SMS;
8. inspect `/healthz` and `/readyz`.

If a critical regression appears, restore the Twilio values from the snapshot immediately.

## 12. Cursor completion rule

Cursor must not answer "done" merely because it changed Twilio.

Completion requires:
- signed webhook smoke PASS;
- press-1 PASS;
- FR/EN/ES real calls PASS;
- authoritative schedule PASS;
- SMS exactly-once PASS;
- private caller PASS;
- health/readiness PASS;
- Guardian PASS;
- rollback proven.

When a bug is found:
1. reproduce it;
2. fix the cause;
3. add a regression test;
4. run Guardian;
5. rerun the failed real scenario.
